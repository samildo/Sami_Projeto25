# Draft genome annotation of the heat tolerant fungi Talaromyces trachyspermus isolated from fruit juice  

This work attmepts to do an initional functional anotation of Talaromyces trachyspermus isolated from fruit juice by implementing varoius bioinformatics tools to try and find specific
proteins related to mycotoxins and heat resistance. 

The repository holds some extended results and most of the dataframes used as well as complimentary scripts.
